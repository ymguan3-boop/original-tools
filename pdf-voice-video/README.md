# PDF 轉語音影片模組（underline-show）

一個**純前端、免後端、免安裝**的網頁工具：選取一份 PDF，自動偵測其中的**底線文字**（或改用手動輸入旁白），以中文語音**逐字同步朗讀**、以黃色遮罩與**即時字幕**即時呈現，並可一鍵**錄製成含語音與字幕的影片（WebM）**。

部署方式是「單一靜態網頁」，故可放上 **GitHub Pages** 供大家直接使用，無需建置伺服器。

> 🌐 **線上部署網址**：<https://ymguan3-boop.github.io/pdf-voice-video/>
> 本 repo（`ymguan3-boop/pdf-voice-video`）的 `main` 分支即為部署來源，推送後約 1～2 分鐘 GitHub Pages 自動更新。

---

## 功能特色

- 📄 直接選擇 PDF 或拖曳進視窗，無需上傳伺服器（所有處理都在瀏覽器本機完成）。
- 🟡 **底線導讀**：自動分析 PDF 底線矩形，把底線文字擷取出來朗讀，並依語音**逐字同步**黃色高亮遮罩。
- ✎ **自訂語音**：為每一頁自行輸入要朗讀的文字，左側同步預覽該頁 PDF，並即時估算秒數。
- 🗣️ 使用瀏覽器內建 **Web Speech API（speechSynthesis）** 中文語音朗讀，可切換語音、調整語速。
- 📝 **字幕**：依語音目前片段**整行一次顯示**，底部 95% 不透明深色底框、金黃高亮字、**單行不換行**（文字過長時自動縮小字級，永遠完整落在底框內）。
- ⛶ **自動全螢幕**：開始播放／錄影自動進入全螢幕，PDF 自動置中；全螢幕時僅右上角保留「回到瀏覽器」按鈕。
- 🎥 **一鍵錄影**：以 Canvas 合成影片（頁面＋高亮＋字幕全部燒錄進去）＋ 僅收電腦（系統）音訊，輸出含語音的 WebM（VP9＋Opus）。

## 使用方式（介面操作說明）

### 1. 首頁
- 點「📄 選擇 PDF 檔案」或直接把 PDF 拖曳進視窗。
- 載入完成會顯示偵測到的頁數與底線段數。
- 選擇模式：**🟡 底線導讀**（自動讀底線）或 **✎ 自訂語音**（手動輸入旁白）。
- 右上「❓ 使用說明」可隨時查看操作與錄影注意事項。

### 2. 工具列（進入模式後置於頂端）
| 按鈕 | 功能 |
| --- | --- |
| 🏠 返回首頁 | 回首頁重選模式 / PDF |
| 第 X / N 頁 | 目前頁面 |
| ✎ 編輯旁白 | 自訂語音模式下開啟旁白編輯器 |
| 語音下拉選單 | 切換中文朗讀語音 |
| ▶ 試播 | 試聽目前頁朗讀（自動進全螢幕） |
| ▶ 播放並錄影 | 直接錄製整份 PDF 的朗讀影片 |
| ◀ 上一頁 / 下一頁 ▶ | 手動翻頁 |
| ↻ 重播 | 重播目前頁 |
| 自動翻頁 | 切換是否播完自動換頁 |
| ⛶ 全螢幕 | 手動進／出全螢幕 |

### 3. 播放與字幕
- 點「▶ 試播」會**自動進入全螢幕**，PDF 置中；停止播放即回到瀏覽器。
- 字幕置於頁面底部，依目前語音片段**整行一次顯示**、**單行不換行**；文字過長時自動縮小字級，一律被包在深色底框內、不會超出底框。

### 4. 全螢幕行為
- 播放／錄影開始 → 自動進入全螢幕。
- 全螢幕時**僅右上角顯示「✕ 回到瀏覽器」**，其餘工具列、縮放、翻頁按鈕全部隱藏。
- 停止播放或錄影輸出完成 → 自動退出全螢幕。

### 5. 錄影
- 點「▶ 播放並錄影」，瀏覽器會要求**分享畫面**；請選取**「整個螢幕」或某個視窗**，並勾選**「分享系統音訊」（Share system audio）**。
- 朗讀語音（speechSynthesis）不會進入「分享此頁籤」的音訊捕捉（Chromium bug 40753195），故**必須分享整個螢幕＋開啟系統音訊**才能錄到語音。
- 程式**不開啟麥克風**，避免錄到外在／環境聲音；錄音時音量已自動放大＋壓縮。
- 程式畫面＋黃色高亮＋字幕會**直接合成**成影片，字幕已燒錄進去；若開錄約 4 秒後跳出「偵測不到系統音訊」提示，代表沒錄到語音，請重新錄製並確認上述選項。
- 播到最後一頁自動停止並下載 `pdf播放錄影.webm`；也可中途按「⏹ 停止」提前結束。

### 6. 鍵盤快捷鍵
`空白鍵`＝播放／暫停　`←` `→`＝換頁　`F`＝全螢幕　`R`＝重播　`Esc`＝關閉彈窗／停止

## 程式架構

採用**單一 HTML 檔**（`index.html`）+ 本機离线 `pdf.js`，全部前端、無後端。

```
underline-show/
├── index.html             # 應用程式主體：結構 + 樣式 + 邏輯
├── lib/
│   ├── pdf.min.js         # 離線 pdf.js 主程式
│   └── pdf.worker.min.js  # 離線 pdf.js worker
├── _inbox.pdf             # 示範樣本 PDF（含底線，可立即試用）
└── README.md
```

### 邏輯模組（皆在 `index.html` 的 `<script>`）

| 模組 | 說明 |
| --- | --- |
| **PDF 載入** | 讀取 `ArrayBuffer`，以 pdf.js 渲染每頁至 `<canvas>`，並「置中」於舞臺。 |
| **底線分析** | 讀取 operator list 的 `rectangle` 與文字座標，交集出「底線文字」與位置，分組為多個 `seg`。 |
| **語音計畫** | 把原文正規化：**保留句讀標點（，。！？；、：）以製造語氣停頓**、略過表情符號、把 `＆→和`、`＋→加` 等轉口語念法，產生 `{speech, toLocal}` 對照表。 |
| **播放與遮罩** | 以單一 `SpeechSynthesisUtterance` 朗讀整頁，用 `boundary` 事件切換底線遮罩（黃色 `overlay`）；另以時間估算作備援，避免語音事件異常時停滯。 |
| **即時字幕** | **整行一次顯示**：片段切換時 `showFull()` 一次顯示完整字幕，`fitSubtitle()` 於文字過長時自動縮小字級使其**單行不換行**並完整落在底框內。 |
| **全螢幕** | `enterFs()/exitFs()` 控制 `requestFullscreen()`；`fullscreenchange` 時隱藏工具列、只顯示右上「回到瀏覽器」，並重新渲染 PDF 置中。 |
| **錄影（Canvas 合成）** | `recCanvas.captureStream(30)` 產生視訊軌；`startRecLoop()` 每影格把「PDF 頁 ＋ 黃色高亮 ＋ 換行字幕」重繪到錄影畫布。 |
| **錄影音訊** | 僅收**電腦（系統）音訊**（不開麥克風），需在分享時選「整個螢幕」並勾選「分享系統音訊」；以 Web Audio 放大＋壓縮混音後接 `MediaRecorder`，並有靜音看門狗提示。 |

### 「主要提示詞（Main Agent Prompt）」

本模組由 AI 代理（agent）依下列**主要提示詞**逐步建置，可供維護與複製重現時參考。包含**介面**與**錄影**之關鍵要求：

> 把 PDF 變成「逐字朗讀、可錄影輸出」的語音影片模組。純前端、免後端、免安裝，離線可用，繁體中文介面。
> 1. **首頁**：標題「PDF轉語音影片模組」，區塊緊湊；兩個模式卡片「🟡 底線導讀」「✎ 自訂語音」；可選 PDF 或拖曳；提供「❓ 使用說明」。
> 2. **工具列**（頂端置中）：🏠 返回首頁、頁碼、✎ 編輯旁白、語音選單、▶ 試播、▶ 播放並錄影、◀ 上一頁、↻ 重播、自動翻頁、⛶ 全螢幕、下一頁 ▶；「▶ 試播」與「▶ 播放並錄影」相鄰。
> 3. **底線導讀模式**：以 pdf.js 讀取底線矩形並對應文字，抽成 `seg`；黃色遮罩與字幕隨語音同步；略過標點與表情符號，避免語音誤唸「分號」等，並提供原文字幕。
> 4. **自訂語音模式**：為每頁輸入旁白，左側即時預覽該頁；留空則 1 秒後自動翻頁。
> 5. **即時字幕**：字幕須與語音**逐字同步**顯示（以語音 boundary 事件驅動，時間估算備援），文字不可過少；字幕背後加**對比色底圖、不透明度約 95%**；文字過多時**自動換行，不得超出文字底框**，不得出現閃爍或位移。
> 6. **全螢幕**：開始播放及錄影時**自動投放為全螢幕**（跳出瀏覽器），PDF **自動置中**；全螢幕時**僅於右上方保留「回到瀏覽器」按鈕**，其餘工具列、縮放、翻頁按鈕一律隱藏；停止播放即退出全螢幕。
> 7. **錄影**：一鍵輸出含語音與字幕的影片。由於 **Chrome/Edge 的 speechSynthesis 語音不會進入「分頁音訊」**（Chromium bug 40753195），故**影片不依賴螢幕擷取**，改以 **Canvas 合成**（渲染 PDF 頁＋黃色高亮＋逐字字幕到錄影畫布）；語音以**麥克風**為保證音源、可再合併系統音訊；輸出 WebM（VP9＋Opus）。

### 錄影技術細節與瀏覽器限制（重要）

- **為什麼不能直接錄「分頁」？** Chrome/Edge 中，`speechSynthesis.speak()` 產生的語音**不會被** `getDisplayMedia({audio:true})` 的分頁音訊軌捕捉（Chromium bug [40753195](https://issues.chromium.org/issues/40753195)）。若直接照螢幕畫面錄製，會得到「有影像卻沒有朗讀聲」的影片。
- **解法（本模組）**：
  1. **影片**：用 `recCanvas.captureStream(30)` 合成——每影格把目前 PDF 頁、黃色遮罩高亮、以及字幕畫到錄影畫布。如此影像與字幕**必定進影片**。
  2. **音訊**：僅收**系統音訊**（`getDisplayMedia` 的 `systemAudio:'include'`），程式**不開麥克風**以避免錄到外在聲音。分享時必須選**「整個螢幕」並勾選「分享系統音訊」**（若分享「此頁籤」則 speechSynthesis 語音不會被收錄）。音訊經 `AudioContext` 放大＋動態壓縮後接 `MediaRecorder`。
- **輸出**：`video/webm;codecs=vp9,opus`（VP9 視訊＋Opus 音訊）。若瀏覽器不支援則依序降級到 vp8、webm。
- **瀏覽器**：建議 Chrome / Edge（Safari 對 MediaRecorder 與語音功能支援有限）。

## 部署至 GitHub Pages

本專案是靜態網站，部署非常簡單：

1. 把 `index.html`、`lib/`（與你可選的樣本 `_inbox.pdf`）推到任一 GitHub 公開 repo。
2. 到 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，儲存。
3. 等約 1～2 分鐘，即可透過 `https://<你的帳號>.github.io/<repo名稱>/` 讓大家使用。

> 🌐 本專案目前已部署至：**<https://ymguan3-boop.github.io/pdf-voice-video/>**
> 來源 repo：`https://github.com/ymguan3-boop/pdf-voice-video`（`main` 分支）。

> 加入一個空的 `.nojekyll` 檔可避免 GitHub 把 `.html` 誤當 Jekyll 處理（本專案其實無此問題，但加上更保險）。

在本目錄開啟一個靜態伺服器即可：
