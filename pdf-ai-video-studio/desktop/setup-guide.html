PDF 智慧影音製作系統｜首次啟動引導

這是隨 Windows ZIP 一起提供的離線說明頁。你只要按步驟安裝必要程式，然後再次雙擊 啟動PDF智慧影音.exe，它就會自動開啟本機 HTML 製片介面。

第一步：Python（基本功能必需）

EXE 沒有找到 Python 3.10–3.14，或安裝後尚未能由系統找到。建議 Python 3.12/3.13 Windows x64。安裝後請關閉程式，重新雙擊 EXE；不必手動建立虛擬環境。

Python 官方 Windows 下載Python Windows 安裝說明

如果安裝後仍偵測不到 Python，請確認 Windows 的 Python Launcher／PATH 設定，以及是否意外啟動 Microsoft Store 的 Python 執行別名。

第二步：基本配音與錄影

Python 偵測通過後，EXE 會詢問是否安裝必要的 Edge-TTS/httpx 套件。安裝完成即自動開啟本機網址 http://127.0.0.1:8765/pdf-ai-video-studio/；程式會顯示互動式設定精靈。錄製 WebM 需要支援 MediaRecorder 的瀏覽器。

Microsoft Edge 官方下載

第三步：選用 AI 文案與 AI 影片

AI 文案可直接在 HTML 精靈內設定你的 OpenAI 相容 LLM，或選擇本機 Ollama。若要使用 Wan2.2、MuseTalk、SadTalker，再額外安裝 ComfyUI、可信的模型權重與相容工作流；沒有 GPU 仍可使用基本 PDF 製片。

Python 套件與雲端 API 需要網路。未選用的模型不必下載。請不要從不明網站安裝來路不明的 EXE、模型節點或 Python 套件。
