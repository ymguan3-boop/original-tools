下載桌面版

DINOv2 語意相似度 · 本機推論 適合需要進一步辨識裁切、重新壓縮、調色等相似照片的審計工作。
  • Windows ZIP，內含 DINOv2 模型與執行檔。
  • 解壓後雙擊「啟動工程照片稽核.exe」，自動開啟瀏覽器。
  • 免安裝 Python / Node.js；影像推論不需網路。
  • 需保留啟動程式視窗，並留意 Windows 未簽章程式提示。

使用線上版

像素＋感知雜湊 · 不使用 DINOv2 適合不想安裝程式、希望立即進行照片相似度初篩的使用者。
  • 透過瀏覽器開啟，不需下載或安裝。
  • 以像素、感知雜湊及色彩特徵進行快速初篩。
  • 支援多資料夾交叉比對、差異說明、Word / CSV 匯出。
  • 照片在瀏覽器處理；可選擇使用需連網的 AI 文字解說。
