Windows 桌面版 v2.5.1｜安裝與操作說明

免額外安裝 Python、Node.js 或本機伺服器｜適用 Windows 10 / 11

請重新下載 v2.5.1 ZIP 並完整解壓縮到新資料夾，不要覆蓋或混用舊版。雙擊 EXE 後在瀏覽器操作；按「開始分析」即完整執行全部跨批次配對辨識，匯出 DOCX 不需重新分析。

下載並完整解壓縮

點選上方「下載 DINOv2 桌面版 ZIP」，在檔案總管右鍵選擇「解壓縮全部」到全新資料夾；避免舊版 JS 與模型檔混用。不要直接在 ZIP 內執行 EXE，也不要將 EXE 單獨移出資料夾。

雙擊啟動程式

開啟解壓縮後的資料夾，雙擊 啟動工程照片稽核.exe。程式會啟動本機服務，並自動開啟預設瀏覽器（建議 Chrome 或 Edge）。

匯入照片並分析

在網頁介面點「多個資料夾（連續選取）」，重複按「選取下一個資料夾」挑選不同路徑來源，最後點「完成加入」，也可從檔案總管一次拖入多個資料夾；至少加入兩個工程照片資料夾，按「開始分析」，系統即自動執行全部照片配對的共同視覺、DINOv2、FAST／BRIEF、SIFT-style 梯度補強、RANSAC、SSIM 與 SHA-256 判別；分析完成後可點擊照片查看差異熱區。所有辨識已在「開始分析」時完成，按「匯出 DOCX 查核報告」直接寫出各技術及比對結果，並記錄特徵點數、內點比例、SSIM 等結果；全部跨批次照片會先完成各項辨識，再依共同分數或幾何同源線索列示。

使用完畢再關閉

使用期間請保持 EXE 啟動後的命令視窗開啟；關閉視窗就會停止本機網頁服務。要再次使用時，只需重新雙擊 EXE。

檔案保留提醒： ZIP 中的 index.html 是瀏覽器介面本體。assets/、models/、comparator-core.js、docxWriter.js 等都需保留；FAST／BRIEF、SIFT-style 梯度補強、RANSAC、SSIM 的程式整合在編譯後的 assets/ 內。請保留解壓縮後的完整資料夾；操作說明已集中在本網頁，ZIP 不必再附獨立的 TXT 說明檔。

兩版的辨識參數及適用範圍

「百分比」有三種不同意義：基礎計分權重、特徵或幾何指標、有效像素占比；都不是同源或違規的統計機率。基礎分數另有可信度封頂與補正，不能直接加權相加推得畫面結果。

辨識參數適用版本功能百分比／指標定義適用範圍與限制
共同視覺初篩分數雙版彙整構圖、明暗與邊緣，排序候選照片0–100 分；基礎權重 pHash 38%＋結構 33%＋邊緣 18%＋dHash 11%，另有門檻上限及補正；不是機率快速初篩；同一門檻可比較；大量裁切時仍可能漏列
pHash雙版比較低頻構圖是否相近相同位元 ÷ 63 × 100%；38% 是基礎計分權重，不是 pHash 正確率重壓縮、縮放；大裁切及高相似紋理須複核
dHash雙版比較相鄰區域的亮暗變化相同位元 ÷ 64 × 100%；基礎權重 11%粗略輪廓；光照與大幅裁切可能影響
明暗結構雙版比較 32×32 灰階的空間布局灰階相關性轉換為 0–100 指標；基礎權重 33%相同場景、局部亮度差；同色背景可能誤導
邊緣一致性雙版比較灰階邊緣方向及強度梯度相關性轉換為 0–100 指標；基礎權重 18%結構與輪廓相近；旋轉、遮擋會降低
像素／色彩雙版像素 RGB 差距及色彩直方圖交集0–100 相似指標；主要供輔助，不直接各占主分數相近曝光與場景；相同顏色不能證明同源
去白邊／區域／位置校正雙版保守去除外側近白邊；比對全圖／中心／去白邊；檢查小位移區域選擇非百分比；位置校正是相關性映射 0–100；±4 格只容許有限位移掃描頁面留白及小裁切；不等於物件分割或透視校正
DINOv2-small CLS僅桌面384 維全圖語意特徵餘弦比對餘弦值 × 100 顯示為分數；不是同源機率；不加入共同初篩門檻同類場景輔助；不同照片拍攝相同物件也可能高分
DINOv2 Patch僅桌面，模型支援時局部 token／區域特徵比對局部餘弦 × 100；模型無局部輸出須顯示未取得局部場景輔助；不單獨認定同源
SHA-256僅桌面確認檔案位元組完全一致相同／不同（無相似度百分比）完全重複檔案；裁切或重存後雜湊通常不同
FAST／方向 BRIEF僅桌面擷取角點與二進位描述子，供跨圖匹配報告匹配點數，非百分比；不是 OpenCV ORB位移、旋轉與部分裁切；少紋理易漏判
多尺度 SIFT-style僅桌面，後備FAST 證據不足時，使用自有 128 維方向梯度描述子報告匹配點數，非百分比；不是完整 OpenCV SIFT較大裁切及區域特徵補強；仍可能漏判
RANSAC僅桌面過濾錯誤對應並檢查相似變換幾何一致內點比例＝RANSAC 內點數／候選匹配點數 × 100%；覆蓋率＝內點座標外接框／384×288 畫面 × 100%同源幾何線索；非透視 Homography、非違規機率
對齊後 SSIM僅桌面評估幾何對齊區域的局部明暗／結構有效區域平均 SSIM 映射至 0–100；不是兩張照片同源機率檢查結構一致，可能受光照、遮擋與雜訊影響
重疊率／差異區域僅桌面標記幾何映射的有效影像範圍及超過閾值的灰階差異重疊率＝有效對齊像素數／兩圖有效像素數較小值 × 100%；差異比例＝亮度差大於 32 的像素／有效像素 × 100%揭露局部驗證範圍；重疊率 100% 不代表影像完全相同
MobileSAM／YOLO兩版均未加入物件分割／辨識，非本次必要功能未執行，不應顯示百分比將來有指定物件數量或輪廓需求才評估
判讀提醒：網頁版以速度為優先，桌面版對全批次配對進行局部幾何驗證。低於共同視覺門檻但符合局部幾何條件者可在桌面版補列。SIFT-style 不是完整 OpenCV SIFT；RANSAC 的「內點比例」不是重複請款機率。OpenRouter 僅於使用者主動同意時作為可見內容說明。

常見問題與資訊安全提醒

為什麼雙擊 EXE 後會開啟瀏覽器？可以刪掉 HTML 嗎？

EXE 只負責在自己的電腦啟動本機 HTTP 服務（127.0.0.1 隨機連接埠）；真正的操作畫面由 index.html 和其他資源提供。因此 HTML 必須保留，不能單獨刪除。

需要連網或安裝其他軟體嗎？

基本 DINOv2 圖像推論使用 ZIP 內的 ONNX 模型和 WebAssembly，無須安裝 Python / Node.js，也無須連網。若自行啟用 OpenRouter AI 文字解說，才需要網路與 API 金鑰；啟用時縮圖可能傳送至第三方服務，應先確認機關資安政策。

Windows 顯示「保護您的電腦」或未簽章警告怎麼辦？

本工具的 EXE 由 GitHub Actions 編譯，未提供商業程式碼簽章。請先確認下載網址是本專案官方頁面，必要時交由資訊單位檢查，確認可信後再依機關規定執行；不要為了使用工具而關閉系統的安全防護。

為什麼 Windows 不能在資料夾選取器中按 Ctrl 一次多選？

Chrome、Edge 的原生資料夾選取對話框通常一次只開放選一個資料夾。因此新版「多個資料夾」會先打開批次匯入視窗：每次選一個不同路徑的資料夾，累積後按「完成加入」；或從檔案總管一次拖入多個資料夾到批次匯入區。想將共同父資料夾內的第一層子資料夾分組，也可按「父資料夾自動分組」。

為什麼打不開網頁或找不到模型？

請先確認 ZIP 已完整解壓縮，並檢查 index.html、assets/、models/ 均與 EXE 位於同一資料夾。如果瀏覽器未自動開啟，可使用 EXE 視窗顯示的 http://127.0.0.1:連接埠/ 網址，貼到 Chrome 或 Edge。

相似度高是否代表施工照片重複請款？

不是。相似度只表示視覺特徵接近，不能直接推論違規或重複請款。仍應比對照片時間、施工日誌、工項數量、契約及驗收資料。

注意：真正包含 DINOv2 的桌面版不能可靠地直接雙擊 file:// HTML 啟動模型，因此採用「雙擊 EXE → 啟動僅供本機存取的網頁」方式。兩版共同視覺分數採同一套初篩演算法，可使用同一門檻比較；桌面版的 DINOv2 與進階幾何證據為額外資訊，不得混為相同指標；任何相似結果都應人工查核。
